# VLzyLauncher v1.0.0-alpha.1-20261003

Release notes prepared for tag `v1.0.0-alpha.1-20261003` on `main`.
This file does not indicate that the GitHub release has been published.

This first alpha establishes the VLzy identity and a working baseline for
development toward 1.0.0.

## Changes

- The app is named **VLzy Launcher** and uses the supplied VL logo.
- About identifies Nadzil123 as the creator and maintainer of VLzyLauncher,
  with its own project, release, issue and contribution links. It
  remains an unofficial Minecraft: Java Edition launcher.
- ZalithLauncher2 is credited as the original codebase of this independently
  maintained hard fork. VLzy's own documents govern its development direction.
- The unused original-launcher updater and automatic sponsorship popup are
  removed. Original-code credits and optional external plugins are retained.
- Project folders, source packages, native bridges and bundled LWJGL classes
  consistently use VLzy names.
- Existing version metadata, selected-version state, favorites and file-manager
  preferences migrate to the new storage names without replacing newer data.
- Local offline profiles work without a Microsoft-account prerequisite.
- Modrinth is the default content source, with the earlier download-completion
  and installer-startup fixes included.
- Installer socket shutdown waits for active reception to finish before the
  next listener reuses its port, preventing an intermittent restart bind failure.
- The interface defaults to English; an existing language choice is preserved.

## Availability

Microsoft sign-in is unavailable until further notice.
CurseForge is unavailable until further notice.

This alpha does not implement every feature described in the living roadmap.
The locally verified package is an ARM64 debug build; production release signing
and a full device/architecture validation pass remain separate requirements.

## Upgrade and verification

The Android application IDs and local debug signing identity are preserved.
Original author credits and required external-plugin compatibility are retained.
Because the launcher activity was renamed, some home-screen launchers may require
re-adding the app icon after an update. Open the new entry from the app drawer.
See [complete naming verification](../project-naming.md) for build results,
artifact details, migration behavior and remaining device checks, and the
[independent project follow-up](../independent-project.md) for the latest About build.
