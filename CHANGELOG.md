# Changelog

Download APKs from
[GitHub Releases](https://github.com/Nadzil123/VLzyLauncher/releases).

## [1.0.0-alpha.1-20261003] — 2026-10-04

### Added and changed

- New **VLzy Launcher** name and logo.
- Updated About page with Nadzil123, project links and credits to ZalithLauncher2.
- Local profiles without Microsoft sign-in.
- Modrinth as the default source for downloadable content.
- English by default, while keeping your existing language preference.
- Existing game settings, favorites and file-manager preferences are preserved
  when updating.
- Removed the old launcher update prompt and sponsorship popup.

### Fixed

- Downloads getting stuck after reaching completion.
- Installer startup and restart failures.

### Availability and upgrade notes

- Available for **ARM64 devices running Android 8.0 or newer**.
- This alpha uses development signing.
- Microsoft sign-in and CurseForge are unavailable until further notice.
- This is an unofficial Minecraft: Java Edition launcher, not affiliated with
  Mojang or Microsoft.
- You may need to add the home-screen shortcut again after updating.
